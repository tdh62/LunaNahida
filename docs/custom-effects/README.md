# 自定义音效使用说明

自定义音效在播放器的「音效」菜单中编辑。频率增益可选择公式或绘制曲线；本文介绍公式、时间响应和延迟，绘图操作见 [自定义增益曲线](../gain-curve.md)。编辑时可以播放歌曲试听；有效的修改会先临时作用于当前播放，只有点击「保存并启用」才会保存。

## 快速开始

1. 在播放器底部打开「音效」菜单，选择「编辑音效」。
2. 点击「新建」，或选中一个内置音效后点击「复制当前音效」。内置音效也可直接作为公式参考。
3. 输入名称，选择「频率公式」，设置频率函数、FIR 点数，以及需要的时间响应或延迟点。
4. 用弹窗顶部的播放和进度控件试听，观察「函数频响」和「时间响应」预览。
5. 点击「保存并启用」。保存后的音效会出现在「我的音效」和播放器的「音效」菜单中。

点击弹窗外不会关闭编辑器。关闭含有未保存修改的弹窗时，需要先确认是否放弃修改。点击「重置」会恢复当前选中音效的内容。

## 频率函数

每条频率函数根据频率 `f`（单位 Hz）返回增益，单位为 dB。`0` 表示该频率不增不减，正数为增强，负数为衰减；它**不表示静音**。

| 设置 | 作用 |
| --- | --- |
| 频率响应 | 输入表达式，例如 `6 / (1 + (f / 180)^4)`。 |
| 起点 Hz、终点 Hz | 指定这条函数的作用频段。远离所有频段及其平滑过渡区的频率保持 `0 dB`。 |
| 歌曲上限 | 勾选后，终点跟随播放器当前音频处理上限（音频上下文采样率的一半）。源文件可能被重采样，因此这个值不一定随切歌变化。 |
| 平滑宽度 Hz | 在起点和终点附近逐渐接入或退出这条函数，避免突然跳变。填 `0` 会取消这一步平滑，但 FIR 本身仍有有限的频率分辨率。 |

一个音效可设置 **1–8 条**频率函数。相邻频段会在边界交叉过渡；重叠频段的增益按 dB 相加。每条函数以及合成后的增益都必须处于 `±24 dB` 内，否则不能保存。若某条频段完全高于当前播放链路的处理上限，它不会产生作用。

编辑器中的「函数频响」预览显示各条函数合成后的目标曲线，并标出频段边界。展开频谱后，橙线显示实际生成的**频率 FIR 响应**，可能因 FIR 点数和窗函数而与目标曲线略有差别；橙线不包含时间响应或延迟混音。实时音频频谱使用另一套纵轴刻度，不要按其刻度读取橙线的 dB 值。

### FIR 点数

FIR 点数决定频率处理的精细度，也会影响计算量和处理延迟。每个自定义音效可单独选择，默认 **8192 点**。

| 点数 | 44.1 kHz 时的约略处理延迟 | 适用情形 |
| ---: | ---: | --- |
| 2048 | 23 ms | 优先降低延迟和处理开销。 |
| 4096 | 46 ms | 日常平衡。 |
| 8192 | 93 ms | 默认值，适合需要较细低频控制的音效。 |
| 16384 | 186 ms | 需要更细分辨率，且可以接受较高延迟。 |

这里的延迟是频率 FIR 本身的近似值，实际播放还受音频设备和浏览器影响。若合成后的频率增益处处为 `0 dB`，播放器会绕过频率 FIR，此时不会产生表中的 FIR 延迟。

## 时间响应与延迟

时间响应表达式使用变量 `t`，单位为秒，结果是每秒的混合增益。播放器始终保留原始声音；表达式生成的响应从原始声音之后开始叠加。填 `0` 表示不添加连续的时间响应。

「响应长度」决定表达式计算的时间范围，可设为 **50–1000 ms**。每个音效还可添加最多 **8 个延迟点**：输入延迟时间（ms）和增益（`-1` 至 `1`）。延迟点时间不能超出响应长度；例如 `190 ms`、`0.45` 会在原声后约 190 ms 混入一份较弱的声音。时间响应和延迟点可以同时使用。

时间表达式在检查位置的结果绝对值不得超过 `20`；延迟点绝对增益之和不得超过 `1.5`。实际生成的时间响应还会检查连续响应与延迟点的总量，过大时需要降低表达式幅度或延迟增益。时间响应为 `0` 且没有延迟点时，播放器会绕过时间卷积处理。

## 表达式写法

表达式是数学公式，不能输入 JavaScript 代码。频率函数使用 `f`，时间函数使用 `t`；还可使用常数 `pi` 和 `e`。

| 类别 | 支持的写法 |
| --- | --- |
| 运算 | `+`、`-`、`*`、`/`、`^`、括号、负号。乘法必须显式写 `*`。 |
| 单参数函数 | `abs`、`cos`、`exp`、`log`、`log10`、`log2`、`sin`、`sqrt`、`tan`。 |
| 双参数函数 | `min(a,b)`、`max(a,b)`、`pow(a,b)`。 |

单条表达式最多 **200 个字符**。除法、对数和开方要在作用范围内产生有限实数；无效值或超限增益会被拒绝。例如 `log10(f)` 在 `f = 0` 时无效，可以提高频段起点，或写成 `log10(max(1,f))`。

## 内置音效参考

内置音效均配置了一条覆盖全频段的函数、8192 点 FIR，以及 400 ms 的时间响应长度；零增益时仍会按前述规则绕过相应处理。复制后可以修改任意设置。

| 音效 | 频率表达式 | 时间表达式 | 延迟点 |
| --- | --- | --- | --- |
| 原声 | `0` | `0` | 无 |
| 低音增强 | `10 / (1 + (f / 280)^4)` | `0` | 无 |
| 空间回响 | `0` | `0` | 190 ms、增益 0.45 |
| 温暖 Lo-fi | `max(-24, -10 * log10(1 + (f / 1100)^4))` | `0` | 无 |

## 可直接尝试的配置

### 低频增强

新建音效，仅保留一条频率函数：

| 项目 | 值 |
| --- | --- |
| 频率响应 | `6 / (1 + (f / 180)^4)` |
| 起点 / 终点 | `0 Hz` / `500 Hz` |
| 平滑宽度 | `100 Hz` |
| 时间响应 | `0` |
| 延迟点 | 无 |

### 两段频率调整

点击「添加函数」，设置两条相邻频段；其余时间设置保持 `0`、无延迟点：

| 频段 | 表达式 | 起点 | 终点 | 平滑宽度 |
| --- | --- | ---: | ---: | ---: |
| 1 | `6` | 0 Hz | 300 Hz | 100 Hz |
| 2 | `-3` | 300 Hz | 3000 Hz | 100 Hz |

在 300 Hz 附近，两条函数会交叉过渡；3000 Hz 以上逐渐回到 `0 dB`。若需要第二条一直作用到最高频率，勾选它的「歌曲上限」。

### 简单回响

频率响应填 `0`，时间响应填 `0`，响应长度设为至少 `190 ms`，添加一个延迟点：时间 `190 ms`、增益 `0.45`。这只添加延迟混音，频谱中的橙色频率 FIR 曲线仍为 `0 dB` 水平线。

### 连续衰减尾音

频率响应填 `0`，时间响应填 `3 * exp(-20 * t)`，响应长度设为 `400 ms`，不添加延迟点。表达式会生成逐渐衰减的连续混合响应；建议从较小幅度开始试听。

## 常见问题

**输入后听不到变化？** 检查是否正在播放歌曲、频率函数是否返回非零增益、作用频段是否在当前播放上限之内，以及是否设置了时间响应或延迟点。`0 dB` 不会改变频率音量。

**曲线与公式不完全一致？** 编辑器显示目标函数，播放时显示实际 FIR 响应。提高 FIR 点数可以改善部分细节，但无法让极窄频段或陡直边界完全精确。

**无法保存？** 查看弹窗内的错误提示，重点检查名称、表达式的取值范围、频段起止顺序、合成增益，以及时间响应总量。最多可保存 **40 个**自定义音效。
