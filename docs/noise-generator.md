# 噪音发生器

在「工具箱 → 噪音发生器」选择类型并点击「播放噪音」。默认音量为 20%，可从较低音量开始试听。

| 类型 | 听感 |
| --- | --- |
| 白噪音 | 明亮、均匀的沙沙声 |
| 粉红噪音 | 较柔和、饱满的沙沙声 |
| 褐噪音 | 低沉、厚重的轰鸣声 |

声音在本地持续生成，无需下载音频，也无需曲库有歌曲。

## 播放控制

噪音面板可以与其他页面同时操作。返回工具箱、关闭面板或切换页面不会停止声音，工具卡片会显示当前类型和播放状态。

底部播放按钮、空格、K 和媒体播放键可暂停或继续；暂停保留类型。「停止噪音」退出噪音模式。噪音播放或暂停时，音量与静音控制作用于噪音，音乐音量保持原值；睡眠定时到期会暂停噪音。

## 切换回音乐

开始噪音会暂停音乐，保留原歌曲、位置、队列与循环模式。停止噪音后可点击播放按钮手动继续音乐；主动选择歌曲、上一首或下一首也会停止噪音并切回音乐。

噪音和音乐不同时播放。其他应用窗口开始播放时，当前窗口的声音会停止。重新启动不会自动播放噪音。

浏览器需要支持 AudioWorklet，并使用 HTTPS 或 localhost；不支持时工具不可用。噪音不经过音乐均衡器或自定义音效。
