# 噪音发生器

点击工具箱入口打开应用菜单，再点击 **噪音发生器** 卡片。在应用中选择白噪音、粉红噪音或褐噪音，点击「播放噪音」。默认音量为 20%，建议从低音量开始。

- 白噪音：明亮、均匀的沙沙声。
- 粉红噪音：较柔和、饱满的沙沙声。
- 褐噪音：低沉、厚重的轰鸣声。

声音在本地持续生成，不下载音频，不需要曲库有歌曲，也不向曲库或音乐播放队列添加条目。

## 后台播放与控制

噪音工具以不锁定页面的浮动面板显示，可以直接操作其他页面。点击「返回工具箱」、关闭面板或导航不会停止声音。菜单卡片会显示当前噪音及播放 / 暂停状态，再点击卡片可继续调整。

底部播放按钮及空格、K、媒体播放键可暂停和继续噪音，即使音乐队列为空也可使用。暂停会保留噪音选择；「停止噪音」会退出噪音模式并释放声音资源。底部也提供停止按钮。

噪音播放或暂停时，底部音量和静音控制作用于噪音，音乐音量保持不变。睡眠定时到期也会暂停噪音。

## 音乐与队列

开始噪音会暂停当前音乐，原播放队列、顺序、歌曲、播放位置和循环模式均保留。暂停、停止或关闭噪音面板不会清空队列。停止噪音后，点击底部播放按钮可从原歌曲暂停位置继续，不会自动恢复音乐。

主动点击歌曲、上一首或下一首时会停止噪音并切换回音乐。噪音和音乐不同时播放；同一应用的其他窗口开始播放也会停止本窗口声音。

## 实现与验证

使用 AudioWorklet 连续生成声音，避免固定音频片段循环。粉红噪音使用多尺度随机采样，褐噪音使用带低频衰减的积分器，保持输出有界。噪音有独立音量，不经过音乐均衡器或音效。

需要支持 AudioWorklet 的桌面 WebView 或安全浏览器环境。启动失败会显示错误，不会更改音乐队列。退出应用会释放音频资源，重启不会自动播放噪音。

验证命令：`node --experimental-strip-types --test src/lib/noise-worklet.test.mjs src/lib/noise-player.test.mjs src/lib/playback-coordinator.test.mjs`。
