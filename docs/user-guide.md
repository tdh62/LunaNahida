# 使用指南

## 添加音乐

桌面版可以选择音频文件或将文件拖入窗口。默认询问临时播放、加入曲库或监听所在文件夹；监听目录可在设置中手动扫描，也可开启启动扫描或定期扫描。文件暂时不可访问时，曲库记录保留，文件恢复后可重新扫描。

临时歌曲只用于当前会话。默认恢复上次播放的曲库歌曲与位置，重新打开后保持暂停，可在设置中关闭。异常退出可能丢失最后几秒的播放位置。

## 搜索、筛选与歌单

歌曲、歌手和专辑支持原文、中文全拼／首字母及日文罗马音搜索，可用空格组合多个词。保留播放器旁的 `search-dict` 目录以启用完整日文读音搜索；词典对特殊人名或作品的读音可能不同，仍可使用原文检索。

曲库可以按名称、歌手、专辑、时长、年份或加入时间排序，并组合搜索、标签与筛选条件。列表中的「定位当前播放」会滚动到当前歌曲；歌曲不在筛选结果中时，该按钮不可用。

新建或编辑歌单时，可选择普通歌单或条件歌单。条件歌单根据关键词、歌手、专辑、标签、来源、可播放状态、收藏、格式、时长和年份等条件自动收录曲库歌曲；空条件代表全部曲库。条件歌单通过修改规则调整成员，改为普通歌单时保留当前匹配结果。

歌单封面可跟随第一首歌曲的封面，也可固定为上传图片。

## 歌词与声音

导入和扫描时优先读取音频内嵌封面与歌词；没有内嵌歌词时可使用同名 `.lrc` 文件。歌词区域提供逐曲时间校准，范围为正负 60 秒：正值延后、负值提前。曲库歌曲独立保存，临时歌曲只在当前会话生效。

音效菜单提供均衡器与 [自定义音效](custom-effects/README.md)，也可 [绘制增益曲线](gain-curve.md)。展开频谱可切换「显示标准音阶」并调整标记数量；标记过密时自动减少显示数量。

音乐和噪音分别记忆音量，静音按钮与快捷键使用相同逻辑。睡眠定时到期会暂停当前音乐或噪音。

## 桌面窗口

底部播放栏可切换到 [迷你播放器](mini-mode.md)。设置中的「最小化到系统托盘」默认关闭；开启后，最小化会隐藏窗口并继续播放，点击托盘图标恢复，右键菜单提供播放控制和退出。关闭窗口会退出应用。

## 网络音乐

「网络歌曲」可打开单个 HTTP(S) 音频链接。在设置中的网络音乐库可添加 WebDAV、FTP、显式 FTPS 目录或 HTTP(S) M3U/M3U8 播放列表。目录递归扫描最多 5,000 首，播放列表最多 1,000 个 HTTP(S) 音频链接；扫描失败不会删除已有歌曲。

缓存空间设置可保留最近播放的 0、5、10、20、30 或 50 首网络歌曲，默认 10 首，每首最多 512 MB。已完整缓存的歌曲可离线播放；在线检测到来源更新时会使旧缓存失效。可单独清空网络音频缓存。

FTP 使用明文传输，私人账户请选择 FTPS 或 HTTPS WebDAV。音频链接会随歌曲保存在本地，过期链接需重新打开。

## 设置与备份

设置支持分类导航与搜索，点击搜索结果可定位到相应选项。

自动备份默认关闭，可选择每天或每周执行，保留 1–30 份，也可立即备份。程序关闭时不会运行备份，重新打开会补做已到期的任务。备份文件位于应用数据目录的 `backups`，不包含音乐文件。

备份列表提供「合并恢复」，保留已有数据并添加缺失数据。条件歌单和歌词校准随数据库备份保存；设置中可查看最近 100 条备份与恢复记录。

缓存清理与数据库备份是不同操作：清理可重新下载的图片和元数据不会删除音乐，内嵌封面与自定义歌单封面保留；WebView 缓存在下一次启动清理。
