# 计时器

点击「工具箱 → 计时器」打开。支持正计时、倒计时、暂停、继续和重置；倒计时提供专注 25 分钟、短休息 5 分钟、长休息 15 分钟预设，也可自定义 1 秒至 7 天。预设只设置本轮时长，不会自动轮换专注与休息。

计时窗口不锁定页面，关闭窗口或切换页面不停止计时。运行中、暂停中或倒计时完成尚未清除时，工具箱按钮旁显示计时按钮；悬浮或键盘聚焦可预览，点击直接打开计时窗口。

状态保存在现有 SQLite 数据库 `preferences` 表的 `work_timer` 记录中，包括模式、状态、首次开始时间、当前运行段开始时间、暂停前累计时长、倒计时时长、完成时间与版本。开始时间由后端生成；只有数据库保存成功才显示已开始。没有新增外部文件或使用浏览器存储作为计时的持久来源。

运行时根据绝对时间计算，不依靠每秒累计，也不每秒写数据库。退出应用期间仍累计运行时间；重新打开后立即恢复。暂停状态在重启后保持暂停，暂停期间不累计。应用关闭期间到期的倒计时在重新打开后显示完成，并提示到期；首次开始时间和实际截止时间保留至重置。正计时不会自动到期。

倒计时结束仅显示提示，不暂停音乐、停止噪音或更改播放队列。重置会结束本轮并清除本轮时间。重新开始创建新的开始时间。

多个应用窗口通过通知与定期同步刷新状态，保存操作带版本检查，避免旧窗口覆盖新状态。依据系统时钟计算；调整系统时间会影响正在运行的计时结果。数据库不可用时显示错误，不把未保存的操作伪装成成功。

验证覆盖数据库关闭再打开、暂停恢复、离线到期、正计时、截止时间、输入校验、旧版本保护和 API 客户端不能指定开始时间；界面验证包含快捷按钮、悬浮预览、音乐并行、页面切换、窄屏与应用后端重新启动。
