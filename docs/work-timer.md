# 计时器

在「工具箱 → 计时器」打开。支持正计时、倒计时、暂停、继续和重置；倒计时可使用专注 25 分钟、短休息 5 分钟、长休息 15 分钟预设，也可自定义 1 秒至 7 天。预设只设置当前一轮，不会自动轮换专注和休息。

## 状态与恢复

关闭计时面板或切换页面不会停止计时。运行中、暂停中或倒计时完成尚未清除时，工具箱旁会显示计时按钮，悬浮可预览，点击重新打开面板。

桌面版保存计时状态。运行中的计时会计入退出应用期间经过的时间，重新打开后恢复；暂停时不累计时间，重启仍保持暂停。退出期间已到期的倒计时会在重新打开时显示完成。重置清除本轮记录。

计时依据系统时钟，修改系统时间会影响结果。独立 Web 模式只保留当前会话，刷新或关闭页面会清除计时。

## 结束提醒

倒计时到期会显示应用内提示。「结束提醒」中的音效与桌面通知默认关闭，可分别开启。音效提供轻柔提示、清脆铃声和电子提示，支持试听与独立音量。

结束提醒不会暂停音乐、停止噪音或改变队列。正计时与手动重置不触发提醒。应用退出期间不会发送提醒，尚未提醒的到期轮次会在重新打开时提示。

桌面版使用系统通知，浏览器使用浏览器通知，开启时可能需要授权。系统通知设置、勿扰模式和浏览器后台策略可能影响展示或及时性；页面恢复后会同步到期状态。通知不可用时仍保留应用内提示。
