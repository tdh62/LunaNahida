# Web 模式

LunaNahida 可在桌面、连接 Go 服务的浏览器和独立网页三种环境运行。

| 功能 | 桌面版 | 浏览器 + Go 服务 | 独立 Web |
| --- | --- | --- | --- |
| 播放、进度、音量、队列 | 支持 | 支持 | 支持 |
| 均衡器、自定义音效、频谱 | 支持 | 支持 | 支持 |
| 曲库、收藏、歌单、标签、历史 | 持久保存 | 后端歌曲持久保存 | 不提供 |
| 文件夹扫描与整理 | 支持 | 使用后端可访问路径 | 不提供 |
| 格式还原 | 安装可选模块后支持 | 后端安装模块后支持 | 不提供 |
| 网络音乐、在线封面与歌词 | 支持 | 支持 | 不提供 |
| 数据备份与恢复 | 支持 | 上传／下载 | 不提供 |
| 原生文件对话框、迷你窗口 | 支持 | 不提供 | 不提供 |
| 计时器 | 保存并恢复 | 保存并恢复 | 仅当前会话 |
| 噪音与睡眠定时 | 支持 | 浏览器支持时可用 | 浏览器支持时可用 |

## 浏览器本地文件

选择或拖入的音频仅在当前会话播放，不上传到 Go 服务，也不加入后端曲库、收藏、歌单或播放历史。标题、歌手和专辑编辑仅对本次会话有效。

每批最多 1,000 个文件；请选择普通音频文件，目录拖放不会递归读取，空文件与加密文件不支持。实际可播放格式取决于浏览器的解码能力。

刷新页面会清除临时歌曲。独立 Web 的外观、声音设置和计时器也只保留当前会话；频谱音阶显示偏好单独保留。

浏览器连接 Go 服务时，路径输入框指向 Go 进程可访问的文件，可能并非浏览器所在设备的文件。

## 运行与部署

```powershell
corepack pnpm dev          # 前端与本地 Go 服务
corepack pnpm dev:web      # 独立网页
corepack pnpm build:web    # 输出静态文件到 dist
corepack pnpm preview      # 127.0.0.1:8082 静态预览
```

通过 HTTP(S) 部署整个 `dist` 目录，为应用路由配置 `index.html` 回退，保留缺失静态资源与 API 的正确响应。不支持通过 `file://` 直接打开；噪音需要支持 AudioWorklet 的浏览器与 HTTPS 或 localhost。

没有 Go 服务时，网页以空队列进入独立模式。已连接的服务发生故障时会提示重试，恢复连接后按提示操作；初次进入独立模式后若再启动 Go 服务，需要刷新页面重新检测。

测试与构建环境要求见 [开发与构建](development.md)。
