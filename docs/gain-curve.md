# 自定义增益曲线

## 设置方式

音效中的频率增益由「频率公式」或「绘制曲线」二选一决定。两套数据分别保留，切换时仅应用选中的设置方式。旧音效默认使用公式，新建音效默认使用绘制。时间响应、回响和五段均衡器仍作为独立处理存在。

设置 → 声音 → 专业调音模式默认关闭。普通模式播放增益限制在 ±24 dB，专业模式允许 ±60 dB。绘图上下限可分别设置；默认 ±12 dB。关闭专业模式保留已保存的完整曲线，在播放时限制超出部分。

## 绘制规则

横轴为对数频率，纵轴为 dB。松开指针完成一笔；一笔经过的最低至最高频率是覆盖范围。同频率多次经过取最后一次的笔迹，支持从右向左绘制。

轻度平滑去掉笔迹抖动，保形插值避免额外峰值。覆盖范围内部的短边缘区连接旧曲线；范围外不改变原曲线。默认过渡最多 0.06 个倍频程，狭窄笔迹自动缩短；用户可以调整笔迹平滑程度。

曲线以频率、增益和必要的插值斜率保存，重开后可以继续编辑。每次修改可撤销或重做，保留最近 40 次操作；保存不会清空当前编辑会话的历史。关闭并重新打开后开始新的编辑会话。

编辑期间切换左侧音效会同步右侧名称、设置方式和曲线，并在本次会话中分别保留未保存草稿及撤销历史。切回可继续编辑。新建草稿也会临时保留，再次点击「新建」可以继续；关闭编辑器前如仍有未保存草稿，会提示放弃修改。

## 试听与实际响应

绘制期间最多约每 120 ms 提交试听更新；播放端会等待当前滤波切换完成，再应用最新一笔。新滤波器先预热，再与旧滤波器过渡；松开后提交完整结果。实线显示目标增益，虚线显示有限长度 FIR 的实际响应，不包括五段均衡器与预衰减。窄频段的实际响应可能与目标不同。

播放时结合实际 FIR、五段均衡器响应与回响混合量计算预衰减，另有峰值压缩保护。它减少大幅提升产生的失真风险，不能保证任何输入都绝不削波。旁路对比跳过自定义音效，五段均衡器继续生效。

## 验证范围

自动测试覆盖局部覆盖及范围外保持、反向笔迹与最后一次经过、抖动平滑、插值不额外放大、专业增益与 FIR、两种设置方式互斥、曲线格式校验和后端保存恢复。

界面验证使用独立音乐库，覆盖专业开关、反复绘制、保存后撤销重做、重载恢复、试听、旁路对比与窄屏布局。主观听感、极窄频段拟合和不同设备输出仍需要用户试听评估。
