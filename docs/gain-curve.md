# 自定义增益曲线

## 选择设置方式

音效编辑器可选择「频率公式」或「绘制曲线」。两套数据分别保留，播放时使用选中的方式；时间响应、回响和五段均衡器可独立设置。

「专业调音模式」默认关闭，普通模式的播放增益限制为 ±24 dB，开启后允许 ±60 dB。绘图上下限可分别调整，默认 ±12 dB。关闭专业模式会保留完整曲线，播放时限制超出部分。

## 绘制与修改

横轴为对数频率，纵轴为 dB。按住指针绘制，松开完成一笔；笔迹只覆盖经过的最低至最高频率，范围外保留原曲线。同一频率多次经过时使用最后一次笔迹，也支持从右向左绘制。

可调整平滑程度，减少抖动；边缘会与原曲线平滑连接。每次修改支持撤销与重做，保留最近 40 次操作；保存不会清空当前会话的编辑历史，关闭并重新打开会开始新的历史。

编辑期间切换音效会保留各自未保存的草稿和撤销历史，切回后可继续。关闭编辑器时，如有未保存修改会提示确认。

## 试听

绘制时可边播放边试听。实线表示目标增益，虚线表示实际滤波响应，不包含五段均衡器与预衰减；窄频段的实际效果可能与目标不同。

「旁路对比」跳过自定义音效，五段均衡器仍继续生效。播放器提供预衰减和峰值压缩保护，但大幅提升仍可能产生失真，建议结合试听逐步调整。

频率公式、时间响应和延迟的操作见 [自定义音效](custom-effects/README.md)。
