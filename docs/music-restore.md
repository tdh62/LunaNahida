# 可选的加密音乐还原模块

「格式还原」由独立的 `LunaNahida.Converter.exe` 提供，可还原 NCM、QMC、KGM、KWM、TM、XM 等加密音乐文件。它保留解码后的音频格式，不提供转码；部分文件需要额外密钥，支持后缀不代表所有文件都能还原。

## 安装、更新与移除

退出播放器，将模块包中的 `modules` 文件夹复制到播放器 EXE 旁：

```text
LunaNahida.exe
modules/
  music-restore/
    LunaNahida.Converter.exe
    README.txt
    LICENSES/
```

重启后，工具箱显示「格式还原」，设置显示自动转换与源文件备份选项。便携版也放在 EXE 旁，不放入 `userdata` 或 `WebView2`。

更新时先退出播放器，替换整个模块目录。移除时退出后删除 `modules/music-restore`。缺少模块或模块不兼容时，相关入口隐藏，普通播放和导入仍可使用。模块不可用后自动转换会关闭，重新安装后需手动开启；已经还原的音乐不依赖模块。

## 播放器内还原

结果输出到原文件夹，目标或备份同名时不会覆盖。开启备份时，源文件放入同目录的 `.lunanahida-original-backup`；关闭备份时，成功发布结果后清理原文件。已入库歌曲保留收藏与歌单关系。

批量处理显示文件数量进度，可取消、继续剩余任务或仅重试失败项。单个文件失败不会停止其余文件；取消会保留已经完成的结果。批次列表只保留当前会话。

解码失败或在解码阶段取消不会修改源文件。异常中断可能留下 `.lunanahida-convert-job-…` 任务目录，提示中会给出路径，请保留目录供恢复使用。

## 中断恢复

打开「工具箱 → 文件恢复」，查看本机登记的任务和监听目录；「检查其他文件夹」可查找其他位置的遗留任务。文件恢复无需安装还原模块。

- **恢复源文件**：核对副本后复制回原路径；原路径已存在文件时另存为 `.recovered-encrypted`，不覆盖已有文件。
- **重新入库**：核对还原结果后加入曲库，并在可以确认原歌曲关联时保留收藏、歌单和手动编辑信息。
- **打开文件夹**：文件改变、同名冲突或记录损坏时，保留文件供人工检查。

恢复操作需要确认。完成后部分任务目录与源文件副本会继续保留；旧记录可能仅支持检查。不要删除可能含有唯一文件副本的任务目录。

## 独立命令行

```powershell
.\LunaNahida.Converter.exe restore "C:\Music\song.ncm" --output-dir "C:\Restored"
```

独立运行不需要播放器、Go、Node.js 或 WebView2，默认保留源文件，同名目标会失败。源文件与结果同名时，请指定不同输出目录。分发或移动模块时保留随包的 `LICENSES`。

源码构建与发布命令见播放器主仓库中的 `docs/development.md`。该模块源码需要额外仓库访问权限，公开主仓库可独立构建精简播放器。
