# 曲库整理

在「工具箱 → 曲库整理」添加本地音乐或文件夹，支持递归扫描多个来源。桌面版可选择文件夹或拖入路径；连接 Go 服务的浏览器使用后端可访问的路径。独立 Web 不提供文件整理，加密音乐需先完成格式还原。

## 选择操作

| 操作 | 用途 |
| --- | --- |
| 按格式命名 | 使用 `{title}`、`{artist}`、`{album}`、`{filename}` 生成文件名，保留扩展名。目标留空时原地重命名，指定目标时移入目标目录。 |
| 按歌手归档 | 按本地歌手标签创建文件夹并移动音乐，保留文件名。 |
| 清理重复音乐 | 识别内容完全相同的文件及元数据相近的候选，逐组选择保留版本。 |
| 合并多个路径 | 将来源目录中的音乐移至目标目录，保留文件名。 |

四项操作独立执行。标签不完整时使用原文件名、未知歌手或未知专辑，并在预览中提示；合唱歌手按完整标签归档。

## 预览与执行

1. 添加来源、选择操作，按需填写目标与命名格式。
2. 点击「预览整理」，检查源路径、目标路径、附属文件和提示。
3. 去重时逐组选取保留版本或全部保留。
4. 勾选确认，点击「确认并执行」。修改配置后重新预览。

预览只读取文件，可取消扫描而不改动文件。每次最多 5,000 首、100 个来源；预览 30 分钟后或应用重启后失效。执行期间请勿关闭应用或编辑相关文件，并确保目标磁盘有足够空间暂存复制文件。

### 去重方式

**完整校验（默认）**读取内容校验值、标签和可用音频参数。内容相同的文件属于完全重复；同歌名、歌手和专辑的文件只是候选，可能包含不同演唱版本。已知时长相差超过两秒的版本不会直接匹配。

**快速匹配**优先使用仍有效的曲库元数据，否则按同名与相同大小寻找疑似重复。它不能证明内容相同，也可能漏掉名称不同且没有可用元数据的重复音乐；所有候选都需要手动选择保留项。

预览只展示实际可读取的音质参数，不按文件大小或扩展名判断「最高音质」。没有完整标签时可能仅按同名列为疑似重复，请逐组核对。

## 歌词、图片与重名

同目录下与歌曲同名的歌词和图片会随音频移动或改名，支持 `song.lrc` 与 `song.mp3.lrc` 等形式。多个音频共用的歌词会复制并保留原件；`cover.jpg`、`folder.jpg` 等非同名共享图片不会自动移动。

目标重名时整组文件添加 `(2)`、`(3)` 等序号，不覆盖已有文件。预览后来源、目标或附属文件发生变化时可能拒绝执行，需要重新预览。快速匹配仅按大小和修改时间检查预览变化，精确内容检查请选择完整校验。

## 恢复与曲库关系

去重不永久删除文件。未保留的音频与附属文件移入源目录的 `.luma-organizer-recovery/<操作编号>/`，恢复区不会再次导入曲库。需要恢复时通过文件管理器移回原位置，再扫描曲库。

完成界面会显示操作记录，记录保存在应用数据目录的 `organizer-history`。普通失败或取消会尝试回滚；断电或强制退出可能需要根据记录检查来源与目标文件，请保留恢复区及所有副本。

已入库歌曲改名或移动后保留歌单和收藏。去重时会合并歌单、收藏、播放历史、队列和自定义标签；未入库音乐不会因整理而自动加入曲库。
